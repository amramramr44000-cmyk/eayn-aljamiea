# عين الجامعة — جامعة ديالى | تطبيق الطلاب

تطبيق الطلاب مستقل عن تطبيق الإدارة، ويرتبطان بنفس مشروع Supabase.

## قبل التشغيل
1. ضع بيانات Supabase داخل `supabase-config.js`.
2. في Supabase افتح Authentication → Providers → Email.
3. عطّل **Confirm email** حتى لا يرسل Supabase رسائل تحقق أثناء التسجيل.
4. شغّل ملفات SQL الموجودة في المشروع بحسب تعليمات الترحيل.

> البريد الإلكتروني في نموذج الطالب يُحفظ ضمن بيانات الحساب ويُستخدم لتسجيل الدخول، لكنه لا يحتاج إلى تحقق بريدي داخل هذا المشروع.
