# عين الجامعة — جامعة ديالى | تطبيق الإدارة العليا

تطبيق الإدارة مستقل عن تطبيق الطلاب، ويرتبطان بنفس مشروع Supabase.

## تسجيل الدخول
الدخول يكون بواسطة **اسم المستخدم + كلمة المرور**.

## إنشاء الحسابات الإدارية
من لوحة الإدارة العليا افتح **مراكز العمل وإنشاء الحسابات**، ثم استخدم نموذج إنشاء الحساب لإضافة:
- اسم المستخدم
- البريد الإلكتروني (بيانات محفوظة للحساب)
- كلمة المرور
- نوع الحساب: موظف مركز أو إدارة عليا
- المركز للموظف
- الاسم الكامل

## قبل التشغيل
في Supabase افتح Authentication → Providers → Email ثم عطّل **Confirm email** حتى لا يرسل Supabase رسائل تحقق أثناء إنشاء الحسابات.

> لا تضع `service_role` أو أي Secret Key في ملفات الواجهة.


## إصلاح حساب إداري قديم
لو أنشأت حسابًا إداريًا بالنسخة القديمة وظهر لك `اسم المستخدم غير موجود أو غير متاح`: شغّل `repair-existing-admin.sql` في Supabase مرة واحدة للحساب المملوك لك، ثم سجّل الدخول باسم المستخدم وكلمة المرور.

## إنشاء الحسابات
صفحة `register.html` تنشئ حسابات الإدارة مباشرة في Supabase Auth مع حفظ `username` و`role` و`account_status=approved`. لا يحتاج تسجيل الإدارة لتحديث ملف `profiles` من المتصفح بعد إنشاء المستخدم.

> للتجربة/النسخة الداخلية، التسجيل الإداري المباشر مفتوح. في الإنتاج يُفضّل حمايته بدعوة أو كود إداري أو Edge Function خادم.
